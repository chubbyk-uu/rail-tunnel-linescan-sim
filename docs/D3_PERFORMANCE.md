# D3 位姿求解提速

## 当前结果

2026-10-05，方法冻结于 `99c6270`。同一组 20 m 综合公开 D1/D2 输入，位姿阶段 **451.874 → 315.800 s，耗时降低 30.1%，约 1.43 倍加速**。窗口内／间独立几何 P95 保持 **0.607／0.662 px**，69,201 个计划点零缺测；完整 CUDA 图像 5,759,600,000 像素、零缺口，84 个独立 CPU 参考点最大量化码差 0。

随后在冻结方法上使用未参与开发的轨道种子 20261213，[12,15] m，新采一组轮径、偏移、双轴倾斜、起伏及假设噪声综合场景。两组 P95 **0.391／0.442 px**、10,656 点零缺测，完整 3 m 图像 863,940,000 像素零缺口；80 个 CPU 点（含 12 个深度点）码差零。25 项阶段 B、实际独立重成像、17 项协议及公开输入审计通过，二进制与源码匹配。

完整测试为 776 项 Python、84 项 C++、5 个 CTest 入口全部通过。20 m 速度和质量来自已见数据回归；新种子独立验收长度为 3 m。两者分开记录，不把同数据复算称为新的 20 m 盲验。

## 瓶颈与改动

| 分项墙钟（嵌套计时，不可把所有行相加） | 原流程 | 提速流程 |
|---|---:|---:|
| D3 位姿阶段 | 451.874 s | 315.800 s |
| 带边界约束的正规方程求解 | 137.551 s | 7.409 s |
| 雅可比组装 | 140.136 s | 139.531 s |
| 光线命中计算 | 65.572 s | 64.875 s |
| 正规方程累加 | 14.814 s | 14.599 s |
| 训练窗口噪声估计 | 24.106 s | 23.930 s |
| 可观测性检查 | 13.003 s | 13.152 s |
| 峰值 RSS | 6.513 GiB | 6.495 GiB |

主要收益来自线性求解。数据雅可比、显式先验及正阻尼构成对称正定的正规方程；自由变量子矩阵也保持这一性质。原通用 LU 的数值行选主元造成额外填充。使用 SuperLU 对称模式、匹配的行列排序及零对角选主元阈值后，实际代表性矩阵的单次分解从约 227 ms 降到 13 ms。每次回代检查分量相对后向误差 ≤1e-10，结果不合格就报错；这一入口只用于上述正规方程，不是通用非对称系统求解器。

节点加密采用 Boehm 插结点，将第一轮训练拟合的曲线精确转换到新样条基上；位置、相位、横向/高度和独立尺度直接复制。第二轮以这条曲线初始化，原始名义 `before` 对照仍按零修正计算。保持原模型、先验、边界、五轮 IRLS、线搜索及停止判据；保持所有匹配、采样和评价格点。两轮累计 GN 迭代 109 →108，本数据上热启动收益很小，不能把主要提速归因于它。

新旧最终节点及字段完全相同，序列化系数最大差约 2.73e-10（各字段为米或弧度），相对尺度差约 1.88e-12。系数并非逐位相同，完整成图和独立几何评价仍必须运行。真实轮径、安装、位姿及网格始终只进入生成与隔离的 `evaluation/`。

## 复核入口与证据

加载已安装的 ROS 和工作区环境后，复用正式保存的公开暂存和匹配；输出目录必须是新的：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 tools/benchmark_d3.py \
  --public sessions/scale20_holdout_seed20261201_20261005/public_run/public \
  --matches sessions/scale20_holdout_seed20261201_20261005/matches \
  --output sessions/D3_PROFILE_NEW --adaptive-attitude --slow-translation \
  --relative-encoder-scale > /tmp/ssb_d3_profile.log 2>&1
```

入口导入已安装实现，核验 D1/D2 哈希和观测身份，再在公开读取审计中运行。只增加内存中的阶段计时和批量报告，不重新采集或匹配，也不产生逐窗口小文件。`profile.json` 记录实际加载的源码哈希、两轮求解、计时和审计；正式优化报告的 `performance.fit_passes` 同时记录两轮初始化与耗时。

## 范围与下一步

当前主要瓶颈转为雅可比组装与光线计算，可进一步研究有界复用或融合数值内核。优先保留这轮已测收益，后续处理接缝亮度与融合，始终保留未经融合的几何对照。20 m 的系数仍为 2047/2048；50 m 需要分段及跨段约束。本文不证明 GUI 实时率或 50 m 支持。
