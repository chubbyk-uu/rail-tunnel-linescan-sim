# 验收协议与当前证据

更新：2026-10-04。操作与算法见 [STAGE_D](STAGE_D.md)，历次失败、调参及旧门限见 [开发归档](history/STAGE_D_DEVLOG_2026-10-03.md)。本页集中记录现行判据、证据边界和可发布结论。

## 1. 判据与输入隔离

主要接缝目标为窗口内和窗口间两组 **P95≤1 px**，输出网格约 0.2 mm；辅助受控门限 3 px。两组预先规划点均不得缺测。原始采 250°、成果固定上方 240°，不事后裁掉边缘。门限通过不代表每点 ≤1 px，四边支撑不代替完整内部覆盖。

生产只读原图、公开曝光/门控与编码器、名义装配和图像估计的标定。真实位姿、轮径、安装、网格及缺陷坐标仅供生成和 evaluation。评价使用 double 光学三角网格求交，保存带方向 dx/dq、材质和窗口内/间分组；不按已知板缝删掉评价点。

D2 留出点测相对拟合残差，常量偏置会被平移吸收，不能单独证明绝对精度。方向相关权重只能从生产训练点估计，评价真值不能回传调参。系统光度偏置约 0.24 px 的历史调查见开发归档，不扣除真值偏差。

## 2. 冻结与取点

方法和参数先冻结，正式新留出使用未参与选择的区段或轨道种子。同一区段同种子复采只验证复现性。预先声明输出域、q 间距 0.2 m、相位 0.25/0.75、每窗 9 个横向点和边缘保护；精确共同观测点在打开真值前保存。窗口内和窗口间分别报告，不只在 D2 训练窗口内评分。

共同域不可测、目标外接缝和原名义位置缺测诊断单列，不能删掉后声称所有角度均有双圈曝光。高环缝占比必须覆盖：环宽 1.2 m 与螺距 0.6 m 的周期关系会使重叠长期压在凹槽上，低占比通过不能推广为通用稳健性。

## 3. 完整入口

先按部署文档安装、生成成套资产；目录必须是新的，源码需提交，脚本会完整构建。以下入口使用 WSL；原生 Linux 的采集路径见 [DEPLOYMENT](DEPLOYMENT.md#原生-linux-启动)，当前不能声称原生整套协议已验收。

```bash
bash tools/run_d3_holdout.sh sessions/FROZEN_NEW local_data/evaluation/FROZEN_NEW \
  12 3 local_data/stage_b/contact_demo > /tmp/ssb_frozen_NEW.log 2>&1
# 可选：D2 与评价采用 4 进程。
# SSB_OFFLINE_WORKERS=4 bash tools/run_d3_holdout.sh ...
```

默认包关闭噪声；带噪声或另一轨道种子的验收需显式指定对应资产包及自己的标定。流程为构建→声明协议→实际采集→独立重成像→阶段 B→原图质量→D1→公开输入 D2/D3→协议核验→独立网格评价。任一步失败不会被改称通过。

## 4. 证据保护

协议 v5 共 14 项：工作树干净、代码提交一致、D2/D3 设置一致、ROI 一致、资产与生产源码哈希一致、公开输入运行、采集溯源哈希、二进制与源码一致、阶段 B 验收、阶段 B 报告哈希、取点协议一致及采集完成。新声明使用 v6，另核对 D2 的窗口间距、尺寸和匹配余量，共 15 项；支持明确冻结可选局部姿态加密，不自动改写历史协议。

`public_reconstruction.v2` 在主进程和数据工作进程中安装 Python 读取审计。路径先解析符号链接，再按暂存公开输入和本次产物白名单检查；运行库资源另行允许，日志写入不授予额外读权限。实际计数必须有读取且违规为零，捕获了违规异常仍不能通过，评分产品哈希必须与该次运行一致。它不是操作系统级沙箱，不覆盖全部原生库、继承描述符或外部进程。历史 v4/v1 的名称黑名单与硬编码零保留原来的较弱含义。

首次阶段 B 报告及 `stage_b_smoke.identity.json` 采用独占创建，不覆盖已有文件或符号链接。哈希记录绑定报告和采集/独立重成像的 session.json，协议核验同时归档其摘要。复查方式：

```bash
python3 -m ssb_tools.validate_stage_b SESSION --compare REIMAGE --read-only
python3 -m ssb_tools.validate_stage_b SESSION --compare REIMAGE \
  --output SESSION/evaluation/reports/recheck_NEW.json
```

独立重成像必须先真正渲染再比对，之后才可去重。比较已共用原图的硬链接不构成新的独立证据。过去两份阶段 B 报告被覆盖，原字节身份无法恢复；说明与清理记录仍保留，不能用新报告补造历史哈希。
