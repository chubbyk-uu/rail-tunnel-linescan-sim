# 阶段 D：采后校正、展开与拼接

当前实现 D1：原始列暗场/平场校正、测量标定的几何映射、名义圆柱展开和逐圈独立条带。匹配、全局优化及接缝融合尚未实施。D1 的初始全图不作为最终拼接精度验收。

## 输入与几何

只读取完成信息中的公开计数/哈希、`config/observable_config.json`、曝光/门控和编码器表、原始 Mono8 块及图像估计的标定文件。不读取 `evaluation/`、仿真位姿、实际轮径、安装真值或场景/缺陷资产。路径检查同时限制目录和文件符号链接，表和实际用到的原图块均校验哈希。

初始扫描轴位置与角度复用公开双测量轮和扫描编码器插值。标靶估计的逆镜头映射给出每个原始列在标靶距离上的轴向坐标，按名义半径/标靶距离缩放至壁面。模型假设扫描轴居中、线方向沿隧道轴向；未知的真实姿态与安装误差不被当作已知量。

暗场和平场在原始列上进行，浮点 DN 不裁剪，原始饱和与坏列保持无效。畸变校正以几何映射保存，与展开采样合并，不先生成拉直图再作第二次空间插值。相邻有效曝光行之间做角向插值，遇到缺行或不连续的触发格点不跨越；有限像素足迹外无效，未标定边缘不外推。

每圈条带可用 `load_bands()` / `BandSampler.sample()` 独立按世界坐标窗口读取，供 D2 比较重叠区域。D1 初始全图在有效条带中选择原始列更靠近传感器中心的一圈，不做跨圈融合，也不拟合车体运动。

## 运行与输出

先构建并载入已安装包；选择现有 20 m 会话中的 `[3,6] m` 作为诊断区域。区域必须位于原定壁面目标内，报告同时保留原目标和诊断区间，不将其冒充完整 20 m 验收。

```bash
source /opt/ros/jazzy/setup.bash
export COLCON_DEFAULTS_FILE=$PWD/colcon_defaults.yaml
colcon build
source install/setup.bash
python3 -m ssb_tools.initial_unroll \
  --session sessions/stage_c_20m_acceptance_20261002/sessions/20261002_113730_eae97f12 \
  --calibration local_data/stage_b/contact_demo/calibration.json \
  --target-x 3 6 --output sessions/d1_NEW > /tmp/d1_NEW.log 2>&1
```

| 文件 | 内容 |
|---|---|
| `sensor_flat.npy` | 相关原始行的暗场/平场校正结果，float32，保持原始列顺序；无效为 NaN |
| `sensor_valid_bits.npy` | 同一数据的有效掩码，按列低位优先打包，一位/像素 |
| `projection.npy` | 原始曝光序号、触发格点、圈号、编码器估计的轴向位置及扫描角 |
| `mapping.npz`、`calibration.json` | 测量镜头映射、有效标定域、名义角向足迹及标定参数 |
| `bands.json` | 每圈对应的行范围、实际记录的曝光边界、目标网格和坐标约定 |
| `mosaic.npy` | 未融合的初始全图，float32 线性 DN；不是最终优化成果 |
| `coverage.npy` | uint16；每个网格像素可用的独立条带数，零表示无效，超过一表示重叠 |
| `source_band.npy` | int16；实际选用的条带索引，−1 表示无效 |
| `preview.png`、`overlap.png` | 缩略图与覆盖预览；不能替代完整网格统计 |
| `overlap_*.png`、`review.html` | 最多三对相邻圈的原尺度复核窗口，固定 0–255 显示，无锐化和自动对比度 |
| `report.json`、`provenance.json` | 缺口/饱和统计、资源与限制、代码和输入/输出哈希 |

每个输出像素的采样来源由条带索引、网格、曝光投影表和镜头映射共同确定，不保存巨大四邻域坐标图。`trace_pixel(output, q_index, x_index)` 可恢复原始块、曝光序号、列号和权重，并与全图 DN 核对。最终优化后仍可从原始列或这些未作空间插值的浮点样本重采样。

## 资源与验收

主数据采用少量连续 NPY 文件、磁盘映射和块读写，不生成数千个小瓦片。单个角向处理块最多一百万输出像素；20 m 等宽目标会自动减小块行数，不因沿用 3 m 默认值而分配过大临时数组。映射页按块释放进程驻留，收尾统一刷新，不逐行 fsync。缩略图同样按少量行分批复制后绘制，避免对巨大映射直接作一次稀疏取样，将大量文件页载入进程 RSS。独立原图和结果哈希只在阶段边界计算。

0.2 mm 网格是输出采样间距，不代表真实光学分辨率提高。3 m ×240° 为 `57596×15000`；当前布局中全图、条带计数和来源索引约 6.44 GiB，再加原始列浮点缓存与打包掩码。输出缓存可以重建，原始采集不可覆盖。D1 尚未优化最终成果的存储格式。

回归包括独立解析斜坡图、非线性镜头映射、非零螺旋运动、原始来源权重、缺行/饱和不补洞、不同块大小一致性、公开路径隔离与 ROI 只读取相关原图。`tools/test_initial_unroll.py` 用仅含公开元数据、测量标定和 ROI 所需原图块的副本复现完整 3 m 结果；未导出的原图块不被读取，该副本不能处理其他区域。结果像素和来源应与原会话运行相同，性能按当前进程 `VmHWM` 记录，避免继承启动器的历史峰值。

## 2026-10-02 实测结果

现有 20 m 原始会话保持不变。最终复核目录为 `sessions/stage_d1_3m_final_20261002/`，其中 `unroll/review.html` 显示初始全图、覆盖图及三对相邻圈的原尺度窗口；根目录 `report.json` 保存公开输入复现与来源核对结果。

- 区域 `[3,6] m`、上方 240°、0.2 mm 网格，共 `57596×15000` 像素；读取 347,020 条相关曝光行，保留 8 个独立条带。
- 展开、校正和预览处理用时 74.30 s，当前处理进程峰值驻留内存 363.94 MiB。该计时到结果报告生成前为止，不含随后输出哈希和独立复核；页缓存和磁盘占用不计入进程 RSS。结果目录约 11.91 GiB，主要为可重建的浮点缓存和展开数组，不表示原始 Mono8 采集变大。
- 更换角向块大小，并移除全部真值目录和非 ROI 原图块后，9 项核心数据内容一致；NPZ 按内部数组比较，其余按文件哈希比较。5 个分散于周向的像素回溯至原始块、行、列和插值权重，重算 DN 与存储值一致。
- 324 个无效输出像素均有原始无效像素支持；本次相关原图中的 182 个无效样本全部为饱和。无效区域保留掩码，不用邻近图像补齐。可用重叠区共 345,541,654 像素，尚未计算图像匹配或优化后的误差。
- 全部 Python 回归 261 项通过。预览曾因直接稀疏读取巨大映射使驻留内存升到约 5 GiB，现已改为批量复制并释放映射页；修复前后预览文件逐字节一致。

复核脚本必须使用已安装包，输出目录必须为新目录：

```bash
python3 tools/test_initial_unroll.py \
  --session sessions/stage_c_20m_acceptance_20261002/sessions/20261002_113730_eae97f12 \
  --reference sessions/d1_NEW \
  --calibration local_data/stage_b/contact_demo/calibration.json \
  --output sessions/d1_PUBLIC_NEW > /tmp/d1_PUBLIC_NEW.log 2>&1
```
